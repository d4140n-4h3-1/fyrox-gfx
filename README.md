# fyrox-gfx (moved)

**This repository is archived. fyrox-gfx now lives in the Hydroxus engine:**
[`Hydroxus/fyrox-gfx`](https://github.com/d4140n-4h3-1/Hydroxus/tree/vulkan/fyrox-gfx) on the
`vulkan` branch. It builds there against the engine in the same commit.

To use it in a game:

```toml
fyrox-gfx = { git = "https://github.com/d4140n-4h3-1/Hydroxus.git", branch = "vulkan", features = ["raytracing"] }
```

The history here stays for reference; new work goes to Hydroxus.
